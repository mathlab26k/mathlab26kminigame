遊び方

操作方法
  1. 画面上部の定理を、ゴール側から証明します。点線のゴールが未証明の「穴」です。定理は閉論理式で、ゴールの左辺は空（局所的な仮定だけ）から始まります。
  2. 理論の公理・スキーマ・証明済みの補題は、左側の「公理・補題」ライブラリにまとまっています。使いたいものをクリックして選び、ゴールをクリックすると、その式を左辺に追加できます。
  3. 追加するとき、先頭の ∀ に代入する項を指定できます。空欄ならその変数は ∀ のまま残ります。命題論理の補題では、命題変数に任意の式を代入できます。
  4. 項は中置演算子で書けます。例: x * y + z（* が + より強く結合）、(x + y) * z、neg(x) + 0
  5. 帰納法スキーマは、論理式 P と帰納法の変数（空欄なら x）を入力してインスタンスを作ります。例: P = 0 + y = y、変数 = y。P には他の自由変数（パラメータ）を含めても構いません。
  6. 定理を1つ証明するたびに、それが補題としてライブラリに追加されます。難しい定理は、先に補題を作ってから挑みましょう。
  7. 左辺・右辺が散らかったら、弱化(左) / 弱化(右) ブロックで不要な式を捨てられます（右辺の弱化は LK と1階述語論理のみ）。
  8. ルールブロックをクリックして選び、適用したい式（チップ）をクリックします。ブロックを適用しても選択は解除されないので、同じブロックを続けて使えます。解除するには、もう一度ブロックをクリックするか Esc キーを押します。ドラッグ＆ドロップも使えます。
  9. Id、⊥L、Refl はゴール全体に適用します。適用先が1つだけなら、ゴールをクリックするだけで済みます。
  10. ∀L と ∃R は項の入力が必要です。∀R と ∃L は新しい変数を自動で選びます。
  11. 書き換え =→ / =← は2回クリックします。先に左辺の等式 s = t を選ぶと、書き換え対象の式の中で書き換えられる項が緑色に光ります。光っている項をクリックすると、その1か所だけを書き換えます。式の光っていない部分をクリックすると、従来どおりその式のすべての出現を書き換えます。
  12. ✕ でその手とその下の部分を取り消せます。Escキーで選択を解除できます。
  13. 1階述語論理モードでは「自動整理」（可逆な手と閉じる手を自動で打つ）が使えます。命題論理モードでは自動整理は使えず、代わりに「ヒント」（正しい次の一手を自動適用、−5点）が使えます。
推論規則（G3系：構造規則なし＋公理導入・弱化）
Id: Γ, A ⊢ A, Δ
⊥L: Γ, ⊥ ⊢ Δ （LM以外）
∧R: Γ ⊢ A, Δ と Γ ⊢ B, Δ から Γ ⊢ A∧B, Δ
∧L: Γ, A, B ⊢ Δ から Γ, A∧B ⊢ Δ
∨R (LK): Γ ⊢ A, B, Δ から Γ ⊢ A∨B, Δ
∨R₁/∨R₂ (LJ, LM): Γ ⊢ A（または B）から Γ ⊢ A∨B
∨L: Γ, A ⊢ Δ と Γ, B ⊢ Δ から Γ, A∨B ⊢ Δ
→R: Γ, A ⊢ B, Δ から Γ ⊢ A→B, Δ
→L (LK): Γ ⊢ A, Δ と Γ, B ⊢ Δ から Γ, A→B ⊢ Δ
→L (LJ, LM): Γ, A→B ⊢ A と Γ, B ⊢ C から Γ, A→B ⊢ C
弱化(左): Γ ⊢ Δ から Γ, A ⊢ Δ（左辺の式を捨てる）
弱化(右): Γ ⊢ Δ から Γ ⊢ A, Δ（右辺の式を捨てる。LK・1階述語論理のみ）
公理の導入: Γ, A ⊢ Δ から Γ ⊢ Δ （A は公理・補題・スキーマのインスタンス）

【公理・補題のインスタンス】
・先頭の ∀x₁…∀xₙ B に対し、項 t₁…tₙ を代入した B[t/x] を導入できる（残した ∀ はそのまま）
・命題論理の補題は、命題変数に任意の式を代入できる
・帰納法スキーマ: P(0) ∧ ∀v (P(v) → P(S(v))) → ∀v P(v)（P は任意の論理式、v は任意の変数）

【1階述語論理のみ】
Refl（等号の論理公理）: Γ ⊢ t = t, Δ
∀R（汎化）: Γ ⊢ A[y/x], Δ から Γ ⊢ ∀x A, Δ （y は結論に自由に現れない）
∃L: Γ, A[y/x] ⊢ Δ から Γ, ∃x A ⊢ Δ （y は結論に自由に現れない）
∀L: Γ, ∀x A, A[t/x] ⊢ Δ から Γ, ∀x A ⊢ Δ （t は任意の項）
∃R: Γ ⊢ A[t/x], ∃x A, Δ から Γ ⊢ ∃x A, Δ （t は任意の項）
=→ / =←（等号の置換公理）: 左辺に s = t があるとき、同じ側の式 A 内の s（または t）の出現を t（または s）に置き換える。一部の出現だけを選んで置き換えることも、すべての出現をまとめて置き換えることもできる。等式自身は対象外。束縛変数による捕獲は禁止

※ 1階述語論理では領域は空でないので、項として使える変数名は自由です。
※ 表示では ∀・∃・¬ は強く結合します。∀x (A ∧ B) のように、二項結合子の式は括弧で囲みます。
※ ¬A は A → ⊥ の略記です。
※ 中置演算子は理論ごとに複数定義でき、優先順位と結合性（既定は左結合）を持ちます。表示では必要な括弧だけが付きます。
