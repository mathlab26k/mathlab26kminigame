𝔞 ⊂ A

Noether環ゲーム

極大イデアルを作ってしまった方が負け

ルール

  1. Noether環 A が与えられ、イデアル I は最初 0 です。
  2. 2人が交互に、I に含まれない A の元 x を指定します。I は I + (x) に置き換わります。
  3. 極大イデアルを作ってしまった側の負けです。
  4. 単元を指定して I = A にしてしまう手も負けとして扱います(単元を選べば極大イデアルを作らずに終われてしまうため)。
  5. よって、極大でも A でもない真のイデアルを作り続ける必要があります。そのような手がなくなった側が負けです。

理論メモ
  • 位置 I は商環 A/I と同一視できます。手は A/I の 0 でない元 x による商 A/I → A/(I+(x)) です。
  • A/I の 0 でない非単元 x で、A/(I+(x)) が体にならないものがあれば、負けずに指せます。そのような x がない位置が「手番側の負け(P位置)」の終端です。
  • PID(ℤ, k[X])では、I = (f) に対し、f の素因数の個数(重複込み)を Ω(f) とします。Ω(f) = 2 のとき手番側が負けで、Ω(f) ≥ 3 または I = 0 のとき手番側が勝ちです。Ω(f) ≥ 3 なら、f の素因数2個の積を指せば Ω = 2 の位置に移れます。I = 0 のときは p² や pq を指せば勝てます。
  • 「有限局所環」モードは全探索で厳密に解くので、CPUは最善手を指し、ヒントも正確です。
  • F_p[x₁,…,xₙ](n ≥ 2)の極大性は、商環が体かどうかを正確に判定しています。0次元でなければ極大ではありません。0次元のときは、Frobenius写像の核と固定空間の次元から判定します。ただし商の次元が36を超えると未判定になります。
  • F_p[x₁,…,xₙ](n ≥ 2)と ℤ[w] の CPU は、有限個の候補を試す簡易戦略です(「相手に安全な手が残らない位置」を探します)。勝敗は証明されていません。「安全な手がない」という CPU の判断も、探索範囲内でのものです。
